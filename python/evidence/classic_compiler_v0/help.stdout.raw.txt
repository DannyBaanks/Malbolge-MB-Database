usage: classic_compiler.py [-h] -o OUTPUT [--map MAP_PATH] [--run]
                           [--runner RUNNER]
                           source

Python literal (def/print/llamadas) → Malbolge Classic autónomo

  source

  -o OUTPUT, --output OUTPUT

  --runner RUNNER       ruta alternativa al intérprete Classic
